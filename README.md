# ASHERA

_Enter Your Era._ A stylized 3D digital twin of Asher's gaming room — plan the layout now, control the room later.

## Setup

```bash
npm install
npx playwright install chromium
npm run dev        # http://localhost:5173  (?view=overview|top)
npm run verify     # must print ALL GREEN
```
